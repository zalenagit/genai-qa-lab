# User story: Checkout

As a signed-in shopper, I want to enter my name and ZIP code and place my order,
so that I receive an order number and know the total I paid.

## Acceptance criteria

1. First name, last name and ZIP code are required.
2. ZIP code must be exactly 5 digits.
3. Sales tax of 8% is added to the subtotal and shown in the total.
4. A successful order shows "Thank you for your order!", an order number and the total.
5. The cart is empty after a successful order.
6. Clear error messages are shown for each invalid field.
